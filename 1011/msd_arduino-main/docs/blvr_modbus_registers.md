# BLV-R Modbus レジスタマップ — 取得可能データ一覧

対象: Oriental Motor **BLV-R** シリーズ ドライバ
出典: `docs/BLV-R_機能-取扱説明書HP-5141J.pdf` 6章「アドレスコード一覧」

## 重要事項（マニュアル p.224）

- **すべての値は 32bit（2レジスタ＝4バイト、上位ワード先・各ワード内ビッグエンディアン）**
- **上位/下位は必ず同時に読み出す**（FC 0x03 で `count=2`）。同時に読まないと値が不正になる
- 単位: 速度 r/min、位置 step、温度 0.1 ℃、電圧 0.1 V、トルク・負荷率 0.1 %、電力 0.1 W

---

## 1. ファームウェアで読み取り中のレジスタ

`motors_modbus.cpp` `update()` 内の周期読み出しで取得し、Arduino → Jetson プロトコルで送信中／getterで参照可能。

| カテゴリ | レジスタ | 名称 | 単位 | 更新頻度 | C++ getter |
|---|---|---|---|---|---|
| 速度 | `0x00CE/CF` | 検出速度 | r/min | ローテーション読み出し | `actualLeftRpm() / actualRightRpm()` |
| 位置 | `0x0120/21` | 検出32bitカウンタ | step | ローテーション読み出し | `actualLeftCount() / actualRightCount()` |
| 異常 | `0x0080/81` | 現在アラーム | コード | ローテーション読み出し | `alarmLeft() / alarmRight()` |
| トルク | `0x00D6/D7` | トルクモニタ | 0.1 % | ローテーション読み出し | `torqueLeft() / torqueRight()` |
| 温度 | `0x00F8/F9` | ドライバ温度 | 0.1 ℃ | ローテーション読み出し | `tempDriverLeft() / tempDriverRight()` |
| 温度 | `0x00FA/FB` | モータ温度 | 0.1 ℃ | ローテーション読み出し | `tempMotorLeft() / tempMotorRight()` |
| 電圧 | `0x0148/49` | 主電源電圧 | 0.1 V | ローテーション読み出し | `vmainLeft() / vmainRight()` |

**ROS2 トピック**: `/msd/encoder` (`std_msgs/Int32MultiArray`) は現在
`[L_rpm, R_rpm, cyl1_pos_0.1mm, cyl2_pos_0.1mm, t_ms]` を 50 Hz で publish。
Modbus 読み出しはRS485バス負荷を抑えるため1サイクル1項目のローテーションで、topicには最後に取得できた値を載せる。

## 5. デバッグ出力の読み方

`Serial`（USB-CDC, 115200 bps）に 2 秒ごとに以下が出力される：

```
MB rpm cmd L=100 R=-100 fb L=98 R=-99 cnt L=12345 R=-12340 \
   trq L=15.0% R=14.8% Tdrv L=32.5C R=33.1C Tmot L=45.0C R=44.5C \
   Vm L=24.5V R=24.5V err=0 almL=0x0 almR=0x0 brk=0
```

| フィールド | 意味 |
|---|---|
| `cmd L/R` | こちらから送信中のRPM指令 |
| `fb L/R` | ドライバから読み取った検出速度 |
| `cnt L/R` | 検出32bitカウンタ |
| `trq` | トルク (% — 定格トルクに対する比) |
| `Tdrv` | ドライバ温度 |
| `Tmot` | モータ温度 |
| `Vm` | 主電源電圧 |
| `err` | Modbus 通信エラー積算 |
| `almL/almR` | 現在発生中のアラームコード（`0x0` = 正常） |
| `brk` | 電磁ブレーキ状態 |

### エンコーダが読めない時のチェックポイント

1. **`almL/almR` が `0x0` か？** — `0x84` ならRS-485通信異常。配線・終端抵抗を確認
2. **`err` が増え続けるか？** — 通信タイミング不良、ドライバ無応答
3. **`fb L/R` が `cmd L/R` に追従するか？** — 追従すれば正常。0 のままなら読み失敗
4. **スレーブIDが正しいか？** — 左=0x01、右=0x02（DIPスイッチ）
5. **Modbusボーレート** — 230400 bps（コード `cfg_.baud`）／ドライバ側の設定と一致必須
