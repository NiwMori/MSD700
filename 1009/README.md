## 追加機能
- フィードバック入力に基づいてアクチュエータを制御し、スローダウンゾーンを実装。  
- アクチュエータの位置に応じて動作を制限またはパルス制御する安全ゾーンを適用。  

## スローダウンゾーン
- **ゾーン 1 (0–5%)** → 強制的に前進（パルスでスロー）。  
- **ゾーン 1.5 (5–6%)** → 前進のみ許可、後退は禁止。  
- **ゾーン 2 (6–20%)** → 前進は通常、後退はスロー（パルス制御）。  
- **通常 (>20%)** → 前進・後退ともにフル動作可能。  

## パルスによるスローダウン制御
- 制限ゾーンでは、**100ms の ON/OFF サイクル**で動作を制御。
